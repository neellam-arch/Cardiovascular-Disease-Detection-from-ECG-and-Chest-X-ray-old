# Cardiovascular-Disease-Detection-from-ECG-and-Chest-X-ray-old
Two deep learning models for cardiovascular disease detection: ECGNet (12-lead ECG, 7 conditions, AUC 0.907) and a DenseNet-121 classifier (chest X-ray, 3 conditions, AUC 0.826), with non-AI verification and a sex-stratified fairness audit. MRes thesis, MIMIC-IV.
